# S1 Prompts

## Prompt 1 (S1.a: inorder)

Write a Racket function inorder-acc (tree acc) that returns the inorder list of a binary tree (value left right) or (), using an accumulator and no append/reverse, and print-inorder that displays it followed by a newline. Use only the allowed built-ins.

## Prompt 2 (S1.b: preorder, postorder, all traversals)

Add preorder-acc and postorder-acc in the same accumulator style, and print-all-traversals that prints inorder, preorder and postorder on three lines.

## Prompt 3 (S1.c: height and leaves)

Add tree-height (height of () is 0), leaf-count (a leaf has two empty subtrees), and print-height-and-leaves that displays the list (height leaf-count).

## Prompt 4 (S1 tests)

Write a Racket test file for 52_q3.rkt that loads its definitions and checks the printed output for t1, t2, t3, the empty tree, a single node and a left-only chain, and checks that no forbidden built-ins are used.
