# S2 Prompts

## Prompt 1 (S2.b: helpers)

Write my-length (tail recursive, named let) and my-map in Racket using only the allowed built-ins.

## Prompt 2 (S2.a + S2.b: insert-if-short and print-insert-result)

Using my-length and my-map, write insert-if-short x lst n that inserts x at the front of every list (at every nesting level) whose original length is less than n, and print-insert-result that reads x, lst, n with read and displays the result.

## Prompt 3 (S2.c: make-inserter)

Write a higher-order make-inserter x len-ok? returning a function that inserts x at the front of every list whose length satisfies len-ok?, and redefine insert-if-short using it.

## Prompt 4 (S2 tests)

Write a Racket test file for 52_q4.rkt that checks the four assignment examples through print-insert-result, my-length, my-map, make-inserter, nesting depth 100 and a 10,000-element list, and checks that no forbidden built-ins are used and insert-if-short is defined once.
