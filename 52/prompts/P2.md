# P2 — Prolog Equation Generator

## Prompt 1 — Expression tree generation

Implement a Prolog predicate that generates binary expression trees from a list of numbers, preserving their order. A leaf represents one number, and internal nodes represent one of the operators +, -, * or /. Use recursion and list splitting. Do not implement the entire assignment.

## Prompt 2 — Expression evaluation

Implement a Prolog predicate to evaluate an expression tree using integer arithmetic. Addition, subtraction and multiplication should work normally. Division must fail if the divisor is zero or if the division is not exact. Intermediate results may be negative.

## Prompt 3 — Canonical expression rendering

Implement a Prolog predicate that converts an expression tree into a canonical string. Follow the required operator precedence and associativity rules. Add parentheses only when required to preserve the expression tree. Do not include spaces.

## Prompt 4 — Equation generation

Implement a predicate that splits a list of numbers into two non-empty contiguous sides, generates an expression for each side, evaluates both sides, and succeeds only when the values are equal. Render the result as a string with exactly one equals sign.

## Prompt 5 — Collecting and counting equations

Implement predicates to collect all valid equations, remove duplicates, sort them, and count the resulting equations. Use the required Prolog predicates and avoid global state.

## Prompt 6 — Testing and review

Review the P2 implementation against the assignment requirements. Test the official examples, empty and single-element lists, exact and non-exact division, division by zero, negative intermediate results, and canonical parentheses. Identify failures and explain the smallest necessary correction.
